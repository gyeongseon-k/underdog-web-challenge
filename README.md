# underdog-web-challenge

## 프로젝트 소개
언더독 레볼루션 신입부원 5일 웹 챌린지로 만든 HTML·CSS 자기소개 페이지입니다.

## 배포 링크
https://gyeongseon-k.github.io/underdog-web-challenge/

## 자기소개
안녕하세요. 컴퓨터융합소프트웨어학과 22학번 김경선입니다.

## 지원 동기
웹 개발과 관련된 기초 지식을 습득해, 더 완성도 높은 결과물을 직접 만들 수 있는 역량을 기르고 싶습니다.

## 배우고 싶은 것
- HTML과 CSS를 활용해 웹페이지의 구조와 디자인을 만드는 기본 방법
- 기초를 바탕으로 Next.js와 같은 웹 개발 프레임워크를 활용하는 방법

## 목표
5일 동안 나만의 자기소개 웹페이지를 완성하기

## 사용한 기술
- HTML
- CSS

## 페이지 구성
- header: 이름과 한 줄 소개
- main
  - 소개: 프로필 이미지와 인사말
  - 관심 분야와 좋아하는 것: 웹 개발, 여행과 드라이브, 운동
  - 배우고 싶은 것: 앞으로의 학습 계획
- footer: 만든 사람 표시와 GitHub 링크
- 반응형: 화면 너비 600px 이하에서 프로필 이미지와 소개 글이 가로 배치에서 세로 배치로 바뀝니다.

## 실행 방법
- 배포된 페이지로 보기: 위 배포 링크에 접속합니다.
- 내 컴퓨터에서 보기: 저장소를 내려받은 뒤(GitHub의 Code > Download ZIP 또는 `git clone https://github.com/gyeongseon-k/underdog-web-challenge.git`), 폴더 안의 `index.html`을 브라우저로 열면 됩니다.
